# Smart-Study-Planner-and-Time-table-Maker
Smart Study Planner is a web-based academic planning tool that helps students manage tasks, track study progress, and automatically generate weekly study timetables based on deadlines and priorities. It is designed to improve productivity, time management, and study organization.  🚀 Features
Features
--Task management system (Add, delete, complete tasks)
--Progress tracking with completion percentage
--Urgent task highlighting based on deadlines
--Weekly timetable generator
--Smart auto-schedule generator based on pending tasks
--Color-coded subjects and sessions
--Dark mode / Light mode
--Local storage support (data saved in browser)
--Printable timetable
--Responsive design
--Smart Auto-Generate Timetable


Technologies Used
HTML
CSS
JavaScript
LocalStorage (for saving tasks and timetable)
Responsive UI Design

This project helps students:

--Manage study tasks
--Track academic progress
--Automatically generate study schedules
--Improve productivity and time management
